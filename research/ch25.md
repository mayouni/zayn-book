## 1. What the chapter does

It shows the verifier as a command a team runs, and the gate a team puts it in, so that a declaration that breaks the law stops
the build. It reads the command's verbs and options as the record holds them, runs the reference command on the exit codes a
build reads (0, 1 and 2) and on the machine form a gate parses, and tells the release v0.2.0 as its notes record it. It shows
what a team chooses (the level, the symbol table, which commands stand in the gate) and what each choice lets through. It opens
Part X, and chapter 8 promised it ("Chapter 25 installs the command", `src/en/08-the-refusal.md:43`).

## 3. The declarations, probed

Each block was written to its own folder as the build writes it (the promise lines included, `tools/book_run.py:46-48`) and run
in text and in `--json`. **All ran as expected**; the promise is kept in each (codes and names). Neutral names: a timesheet
desk (an employee enters and submits the week, a manager reviews the team's weeks). None of these scenes is in chapters 8, 9,
17, 22, 23 or 24.

**Block 1. `week.zayn`: a change the gate stops.** Built on the fixture `read-act-collapse.zayn` (a screen that reads and acts).

```zayn week.zayn
DEFINE SCREEN timesheet_week (
  SATISFIES [READ, ACT],
  ALWAYS_REACHABLE [UNDO]
)
//--> READ_ACT_COLLAPSE timesheet_week
```
In words (proposed): On the week's timesheet, a user reads the hours, and the same screen submits them; undo stays within reach.

```
week.zayn:1  error  READ_ACT_COLLAPSE  timesheet_week
    A reading surface mutates: SATISFIES holds READ and ACT.
    Rule 16 · Intentional Clicks · Article II

1 error(s), 0 warning(s) across 1 file(s) at level 2
```
Exit **1**. `--json`: `"counts": {"errors": 1, "warnings": 0}`, `cites: ["rule:16", "article:intent"]`. Claim: a refusal makes the
command answer 1, and a build that reads it stops. `ALWAYS_REACHABLE [UNDO]` is there to keep one finding: without it the same
file also gets `MISSING_UNDO` (probed: 2 errors, exit 1).

**Block 2. `week.zayn`: the repair the gate lets through.** Built on `read-act-lawful.zayn` (reading and acting on two surfaces).

## 4. The principle

Proposed bold sentence, in the book's words: **A gate reads one number: 1 when the verifier refused a declaration, 0 when it
refused none, warnings included, and 2 when it could not read what it was given; the build goes on at 0 alone.**

the three forms; this chapter puts the number to work). The gate's force is the law's: a citation stops the build, and the
answer is a repair or an amendment (chapter 8). What the gate stops depends on what the team gives it: the files, the level and
the table.
