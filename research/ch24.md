## 1. What the chapter does

It shows the file `haro/zayn.gbnf`: a grammar for constrained decoding, which is a way to make an AI model write only text that a
grammar accepts. The file is written by a script of the record from the language's second declaration, written in Haro, and it
fixes the shape of a declaration and leaves its meaning to the verifier. The chapter reads the file line by line beside the
language's grammar (chapter 7 gives that grammar; this chapter cites it), runs one declaration in the verifier's form and the same
in the grammar's form, and tells what the verifier answers to each, then what the record's mechanical translation produces. It
ends on the question the record holds open: which written form an AI agent bound by the grammar is to write, a ruling that waits
for the author (LANG-RECORD-GAPS-01 (c), `research/REQUESTS.md:69`).

## 4. The principle

The record returns to one sentence, on the site's generate page: "The grammar narrows what a generator can say, and it does not
make what the generator says lawful." (`site/generate.html:110`). The grammar's own header says it shorter: "the decoder holds the
shape" (`haro/zayn.gbnf:5`). The front page's caption says it a third time (`index.html:360`).

Proposal for the bold sentence, in the book's words:

**A grammar fixes the shape a generator can write; the law's refusals stay with the verifier, and the two must agree on the form
first.**

Marked: the clause "and the two must agree on the form first" is the finding of this research; the ruling LANG-RECORD-GAPS-01
(c) would decide how they agree (section 12, F11).

## The probe's code (for a fresh verifier)

The grammar probe, `gbnf-check.js`, as run (it read `../zayn-adaecc271/haro/zayn.gbnf` from the probe folder):

```js
const fs = require('fs'), path = require('path');
const G = fs.readFileSync(path.join(__dirname, '..', 'zayn-adaecc271', 'haro', 'zayn.gbnf'), 'utf8');
const rules = {};
for (const line of G.split(/\r?\n/)) {
  if (!line.trim() || line.startsWith('#')) continue;
  const m = /^([A-Za-z0-9_]+)\s*::=\s*(.*)$/.exec(line); rules[m[1]] = m[2];
}
const esc = s => s.replace(/[.*+?^${}()|[\]\\\/]/g, '\\$&'), cache = {};
function compile(name, stack = []) {
  if (cache[name]) return cache[name];
  if (stack.includes(name)) throw new Error('recursion at ' + name);
  const src = rules[name]; let i = 0;
  function alt() { const p = [seq()]; while (src[i] === '|') { i++; p.push(seq()); } return p.length > 1 ? '(?:' + p.join('|') + ')' : p[0]; }
  function seq() {
    let out = '';
    for (;;) {
      while (src[i] === ' ') i++;
      if (i >= src.length || src[i] === '|' || src[i] === ')') return out;
      let atom;
      if (src[i] === '"') { let j = i + 1, lit = '';
        while (src[j] !== '"') { if (src[j] === '\\') { const n = src[j + 1]; lit += n === 'n' ? '\n' : n === 't' ? '\t' : n === 'r' ? '\r' : n; j += 2; } else lit += src[j++]; }
        atom = '(?:' + esc(lit) + ')'; i = j + 1;
      } else if (src[i] === '[') { let j = i + 1; while (src[j] !== ']') { if (src[j] === '\\') j++; j++; } atom = src.slice(i, j + 1); i = j + 1;
      } else if (src[i] === '(') { i++; atom = '(?:' + alt() + ')'; i++;
      } else { const m = /^[A-Za-z0-9_]+/.exec(src.slice(i)); atom = '(?:' + compile(m[0], stack.concat(name)) + ')'; i += m[0].length; }
      if ('*+?'.includes(src[i] || 'x')) atom += src[i++];
      out += atom;
    }
  }
  return (cache[name] = alt());
}
const ROOT = new RegExp('^(?:' + compile('root') + ')$');
for (const f of process.argv.slice(2))
  console.log(path.basename(f) + ': ' + (ROOT.test(fs.readFileSync(f, 'utf8').replace(/\r\n/g, '\n')) ? 'a sentence' : 'NOT a sentence'));
```
