# What the book's readers taught, for the Zayn site

Written at the end of each part, never before its fresh readers have read (the contract, section I). It is for the Zayn session,
which reads the rows against the live pages and orders the site's desk, one remark at a time, each with a check that fails first.
This book never edits the site and never opens a page of it to change it.

**How to read a row.** *The sentence* is the one sentence that defines the concept, as it stands in the chapter. *The stumble* is
what a fresh reader quoted, on the draft they read, and what repaired it. *Read again?* says whether the sentence was in the draft the
readers read, or was written from their finding and waits for its own fresh reading. *The site page* names the page of `site\` (at
the pin, `adaecc2`) that teaches the same concept; what it says today is for the Zayn session to read at the live page.

## What the readers named, beyond single sentences

- **The clearest plates**: 8.2 (a repair), 9.1 with 9.2 (the same file with one more input), 6.3 (`NAVIGATE`). A pair teaches; a refusal alone leaves the reader waiting.
- **One thing, one word.** The pilot's designer counted six words for one thing (refusal, finding, error, violation, diagnostic, defect) and three for the drawn interface. The book now keeps: a finding, a refusal when it is an error, a diagnostic for a kind of finding; the drawing, and the painted page in a browser (`research/METAPHORS.md`).
- **A sentence of the record is quoted as the record's.** Where a page reused a sentence of the specification as its own prose, a verifier found it each time; the sentence is now in quotation marks with its source.
- **What a page says ran, ran.** Three verifiers each found a sentence about a run that no run of the page backed. Each became a run plate.
